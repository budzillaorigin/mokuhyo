# content/

Build output of `tools/` (content packs per language under `packs/<lang>/`, the model manifest). Never hand-edited.
Large built files (`*.sqlite`, model weights) are git-ignored; rebuild them with the commands in `tools/README.md`.
`models/manifest.json` is committed: it lists every downloadable model with its SHA-256 and provenance (CLAUDE.md rule 13).
